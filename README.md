# RAG-валидатор архитектурных решений и ТЗ
*Суть:* Ассистент, который берет черновик ТЗ, ER-модели баз данных или C4/IDEF0 диаграммы проекта и проверяет их на соответствие жестким паттернам проектирования или ГОСТам.

*В чем фишка:* Идеально ложится в формат серьезной университетской работы. Система помогает автоматизировать проверку архитектуры автоматизированных информационных систем (АИС) до того, как будет написана первая строчка кода.

*Юзкейс:* Загружается описание микросервиса, а RAG находит архитектурные узкие места (например, отсутствие кэширования при высоких нагрузках) на основе загруженной базы best-practices.
