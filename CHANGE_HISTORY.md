# Журнал изменений проекта (Change History)

## [2026-11-21] — Приёмочное тестирование, фикс сборки и отказ от нерелевантных запросов (Илья)
### Изменено и исправлено:
- `pyproject.toml`: добавлена конфигурация `build-system` (`setuptools.build_meta`) и явный поиск пакетов (`[tool.setuptools.packages.find] include = ["app*"]`) для корректной установки через `pip install -e .` в flat-layout репозитории.
- `Dockerfile`: оптимизирован порядок копирования файлов проекта перед сборкой и установкой зависимостей.
- `app/rag/text.py`: расширен список стоп-слов вопросительными формами, добавлены `DOMAIN_KEYWORDS` и функция `is_domain_relevant` для централизованной фильтрации непрофильных запросов.
- `app/api/services.py`: интегрирована проверка предметной области запроса перед формированием ответа, обеспечивающая возврат `refused: true` для вопросов-ловушек (например, кулинарных рецептов).
- `benchmark/run.py`: подключена централизованная функция `is_domain_relevant` из `app.rag.text`.
- Выполнено приёмочное тестирование: 8 юнит-тестов (100% pass), бенчмарк (Recall@5 = 1.0, MRR = 1.0, CRR = 1.0), проверка 5 сценариев быстрого запуска в веб-интерфейсе на http://127.0.0.1:8000.

## [2026-11-21] — Контрольная точка №2 (KT2): Полноценный RAG, Бенчмарк и Корпус
### Добавлено:
- Полноценный корпус знаний из 30 документов (`D01.md` – `D30.md`) по ГОСТ 34.602-2020, паттернам проектирования (SOLID, GoF) и микросервисной архитектуре.
- Самописная реализация алгоритма Okapi BM25 в `app/rag/bm25.py` со Snowball-стеммером для русского языка.
- Модуль chunking Markdown-документов по заголовкам второго и третьего уровня (`app/rag/corpus.py`).
- RAG-пайплайн с вызовом LLM и строгой верификацией источников (`app/api/services.py`).
- Бенчмарк-набор на 15 вопросов: 10 обычных с >=3 релевантными документами и 5 вопросов-ловушек (`benchmark/questions.jsonl`).
- Автоматизированный скрипт расчёта метрик Recall@k, MRR, CRR (`benchmark/run.py`).
- Интеграционные и юнит-тесты (`tests/test_bm25.py`, `tests/test_corpus.py`, `tests/test_api.py`).
- Правила для агентов `AGENTS.md` и спецификации `spec/product/kt2.md`, `spec/tech/rag.md`.
